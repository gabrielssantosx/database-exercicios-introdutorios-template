# Guia de desenvolvimento e versionamento

## Commits sugeridos
```bash
git commit -m "chore: inicia estrutura do projeto"
git commit -m "docs: registra requisitos do exercicio 01"
git commit -m "docs(db): adiciona mer do exercicio 01"
git commit -m "docs(db): adiciona der do exercicio 01"
git commit -m "feat(db): cria tabelas do exercicio 01"
git commit -m "data(db): adiciona massa de dados do exercicio 01"
git commit -m "feat(sql): adiciona consultas do exercicio 01"
git commit -m "docs: adiciona evidencias do exercicio 01"
```

Evite commits como `update`, `teste`, `final` ou `coisas`.
