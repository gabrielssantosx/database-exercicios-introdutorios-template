# Banco de Dados — Exercícios Introdutórios

Repositório-base para as atividades introdutórias de Banco de Dados da disciplina **PI II — Projeto Integrador II (Aplicações Web Dinâmicas)**.

## Fluxo de trabalho

Para cada exercício: **Requisitos → MER → DER → DDL → DML → DQL → Evidências**.

## Regras
- Não alterar a estrutura de pastas.
- Não entregar todo o trabalho em apenas um commit.
- Não utilizar dados pessoais reais.
- Revisar os dados gerados por IA.
- Não versionar senhas ou credenciais.
- Os scripts devem executar em MySQL.
- MER e DER devem ser produzidos pelo aluno.
